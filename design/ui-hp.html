🔑 Urutan halaman (sesuai koreksi 25 Sep)

📊 Dashboard ( pertama)  →  🧾 Transaksi (INTI)  →  🧩 Plugin (opsional)

  • Dashboard = halaman pertama — daftar sumber fund + saldo akhir, total, ringkasan
  • Transaksi = INTI — tempat mencatat. Pindah ke sini lewat tab bawah “🧾 Transaksi”
  • Plugin (Rutin, Belanja, Wishlist, Investasi, Report) = opsional.
    • Dilepas semua → transaksi tetap bisa diinput, hanya lebih repot
  • 🎯 Yang wajib selesai lebih dulu = Transaksi

⬛⬜ Warna — hanya 3 tempat ini yang berwarna

  • ⚠️ Peringatan (kuning) — mis. "2 tagihan jatuh tempo"
  • 🔻 Saldo di bawah minimum (merah)
  • 🔴 Bahaya (merah) — mis. "sisa setelah rutin negatif", tombol Batalkan

Selain itu hitam-putih. Debit dan Kredit dibedakan oleh tanda + / −, bukan warna.
